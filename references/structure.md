# Phase 1 — Structure

Load only during phase 1. Full-file reads this phase: at most 15.

## Docs links (mandatory script)

```bash
rtk proxy python3 "$HOME/.agents/skills/codebase-audit/scripts/docs-check.py" "$WORKSPACE" "$ROOT"
```

- `broken_links[]` → Docs. Minor. Major if `from` is the root README **and** href is an install/getting-started path.
- `promised_missing[]` (README backtick `src/...` that does not exist) → Docs, Major if it is advertised as the main entry; else Minor.
- Do not invent product features from headings. No NLP backlog. Only missing paths the docs already named.

## Promises (mandatory script)

```bash
rtk proxy python3 "$HOME/.agents/skills/codebase-audit/scripts/promises.py" "$WORKSPACE" "$ROOT"
```

- `missing_paths` (CI / package.json script path yok) → Docs or Functional correctness, Major if it is the advertised start/test command. Dedup with `docs-check.py` `promised_missing` (same path → one CA-NNN).
- `plist_unused` (privacy key var, sembol yok) → Docs, Minor. Dead permission copy.
- `plist_missing` (sembol var, key yok) → Security architecture, Major. Only when **one** XML `Info.plist`. `plist_missing_skipped_multi` or `binary_plist` → skip reverse check, Info.
- `haystack_truncated` or `missing_complete: false` → do not claim CI/plist cross-check is exhaustive; not CLEAN on that evidence.
- Do not invent features from plist keys that are unused. Unused key = copy rot, not “add camera”.

## God files

- Source file **>800 lines** = Major candidate (Maintainability). 800 ≈ one file a reviewer cannot hold.
- Skip generated/minified even if >800 (inventory already dropped them from `top_by_lines`).
- Doubt it is generated (header "Code generated by", `@generated`) → Info, not Major: "generated mi?"
- For a god file: first 80 + last 40 + scan defs. Why one file. `Yön:` split direction, no patch.
- Monorepo: flag god files **per `package` field**, not one undifferentiated list.
- iOS `Pods/` / `DerivedData` are pruned — do not re-walk them.

## Layout

- Entrypoint vs domain vs infra vs UI. Use inventory `entrypoints`.
- Same job in two folders.
- Catch-all `utils/` / `helpers/` dumping ground.
- Tests missing next to a core package (pattern, not every file) → Minor/Info.

## Docs hygiene (beyond the script)

- README describes a module with no matching code path (not already in `promised_missing`) → Docs.
- Core package with no mention in README/docs → Docs, Info.
